一、环境要求
----------------------------------------
  1. MuMu 模拟器（Android 12，x86_64），必须开启 ROOT 和 ADB（见安装图解 图一/图二）
  2. Python 3.9+
  3. Play 商店已登录 Google 账号，且已绑定付款方式
     （免费试用也要验证卡，$0 不扣款）
  4. frida 必须是 16.x（17.x 移除了 Java bridge，全部失效）


二、安装
----------------------------------------
  双击  一键安装环境.bat
  （安装脚本最后会自动自检；想单独再查一次就运行 一键安装环境.bat check）

  自检全绿才可以跑：
    OK 设备已连接
    OK frida-server 已启动
    OK 计费模块已就位
    OK Play 商店进程在跑
    OK frida：16.5.9

六、SKU 命名体系
----------------------------------------
  g1.<档位>.<周期>_eft               免费试用（extended free trial）
  g1.<档位>.<周期>_ip_<N>p[.acq|.wb] 付费首期优惠（N = 折扣百分比）
  g1.<档位>.subs_variant             订阅变体（承载多个 offer）

  档位：
    2tb.ai               Google AI Pro (5 TB)        <- 主力
    2tb.ai.subs_variant  Pro 5TB 试用变体
    20tb / 30tb          Ultra（现已无促销）
    ai.pro               Ultra 30TB（现已无促销）

  周期：
    1month / 2months / 3months / 4months / 6months
    12months / 15months / 18months / 24months
    1mo / 3mo / 6mo / 12mo / 1year

  规律：
    - _eft 档必须【不带】.acq / .wb 后缀，加了就查不到
    - _ip_Np 档有的带 .acq，有的带 .wb，有的都不带，必须逐个试
    - 没有 9months / 24months 的 _eft 档


七、常见问题
----------------------------------------
  Play 商店闪退
    -> 模拟器缺 Google 服务框架，用 MuMu 自带的「Google 安装器」装全套

  查询全空（Play 商店在跑）
    -> 账号卡在验证页（MinuteMaidActivity），在模拟器里完成 Google 账号验证

  查询全空（Play 商店没跑）
    -> 重启模拟器，打开 Play 商店

  收银台一闪就没
    -> 付款方式被拒，换一张卡

  app_not_started
    -> App 启动慢，脚本已改轮询 25 秒；仍失败就手动打开 Google One 再跑

  frida 连不上
    -> adb forward tcp:27042 tcp:27042，或重启 frida-server

  device not found
    -> 图二的 ADB 没开，或端口不对（用 --serial 指定）
